# 🤖 MCP Servers

Each subfolder contains a complete MCP server implementation.

## Available MCPs

### 1. N8N Automation (`n8n_automation/`)
Build, test, and deploy N8N workflows via AI commands.

### 2. Agent Builder (`agent_builder/`)
Create agents using ADK, CrewAI, Langbase, A2A, AGUI frameworks.

### 3. Local Control (`local_control/`)
Execute system commands, control applications, automate browser.

### 4. Cloud Services (`cloud_services/`)
Integrate with GCP, WhatsApp, GitHub Actions.

## Structure

Each MCP folder contains:
- `README.md` - Detailed documentation
- `server.py` - Main MCP server
- Implementation files - Specific functionality

Check individual README.md files for details.
